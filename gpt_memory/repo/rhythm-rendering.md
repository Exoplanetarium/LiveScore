- detect_note.py now regularizes detected beats into a local tempo curve, reconciles onset-driven durations with acoustic offsets, and emits backend timing authority fields such as start_beat/end_beat.
- Audit on finalized live/classic_full_pass clips showed the exported MIDI path is faithful to raw time_seconds/duration_seconds, while the rendered score follows backend-authored start_beat/note_divisions; clip_002 had p50 onset drift about 0.152 beats and p50 duration drift about 0.116 beats, with chord dedupe contributing 0 suppressed notes.
- Larger score failures on clips like clip_001 and clip_014 coincided with detect_note.py refining tempo upward to inflated BPM values before beat-grid quantization, so the notation fields can drift badly even when raw event timing remains usable.
- detect_note.py refine_tempo_onset_grid now probes a few meaningfully slower tempo candidates through the actual beat-grid quantization pipeline before finalizing a fast BPM; this guards against doubled-tempo winners that have lower onset-grid error but much worse emitted notation.

LESSONS LEARNED - Things NOT to do on this project
===================================================

1. Do NOT use mixup augmentation (--mixup-alpha > 0) for training.
   - This project does dense per-frame multi-label detection (onset, frame, velocity, note_value).
   - Mixup blends two samples and their labels together, which destroys the sharp binary onset targets.
   - Result: F1 score stuck around 0.58-0.65, unstable, unable to improve even after 26 epochs.
   - Mixup is designed for whole-input classification tasks, not frame-level detection.
   - Default was changed back to 0.0 after wasting a full training run.

2. Do NOT use multi-resolution STFT (adding n_fft=4096) to improve bass note separation.
   - Already empirically proven: 1098-feature ensemble (3 STFT sizes + CQT + HPSS)
     performed WORSE (onset F1=0.72) than 229 mel bins alone (onset F1=0.73).
   - n_fft=4096 at 16kHz means 256ms window — smears onsets across quarter second.
   - Kong et al. achieves 96.72% onset F1 with a SINGLE STFT (n_fft=2048, 229 mel).
   - Mel filterbank at 229 bins with fmin=30Hz already has fine resolution at bass.
   - Better to spend model capacity on larger models than multi-res features.

3. Do NOT use focal loss (gamma > 0) for this task — empirically causes worse plateau.

4. Do NOT use cosine annealing with warm restarts — causes loss spikes. Noam schedule is better.

5. Do NOT use coherence smoothing on rhythm quantization output.
   - Empirically degrades IOI accuracy by -8.2% on MAESTRO test set.
   - Coherence measures consistency, not correctness. It flattens intentional
     rhythmic variety (e.g., mixed eighths and quarters) to the dominant value.
   - apply_coherence_smoothing() in detect_note.py is now disabled (returns unchanged).

6. Do NOT stack heterogeneous features on the same axis for conv layers.
   - Multi-resolution STFT ensemble (1098 features: 3 mel + CQT + HPSS + onset funcs)
     performed WORSE than single mel spectrogram (229 bins), even at comparable param count.
   - Three reasons: (a) conv layers can't meaningfully combine semantically different
     features on the same axis (mel bin convolved with HPSS harmonic = nonsense),
     (b) different STFT window sizes create conflicting temporal signals at the same
     time step (sharp onset from 1024 vs smeared onset from 4096),
     (c) redundancy wastes capacity — model learns "these features are the same"
     instead of learning useful patterns.
   - Let the network learn its own multi-resolution representations from a clean,
     consistent input via depth, attention, and dilated convolutions.

7. Do NOT evaluate model note_value predictions against GT quantized with a different
   class boundary function.
   - If the model predicts in 12-class space, GT must be quantized using the model's
     own NOTE_VALUE_BEATS boundaries, not a separate function (dn_duration_to_note_value).
   - Mismatched boundaries caused a phantom accuracy drop from 0.491 to 0.293 after
     adding dotted_32nd/dotted_16th classes — wasted 6 hours of training.
